# 🛡️ Junior Security Analyst Intro

## 🎯 Objective
Learn about the responsibilities of a Junior Security Analyst and understand how a Security Operations Center (SOC) team works together to defend an organization.

---

## 🧠 Key Takeaways

### Junior Security Analyst (SOC Level 1)
* Works in a **24/7 Security Operations Center (SOC)**.
* Monitors and investigates security alerts.
* Performs the initial analysis of alerts before escalating complex cases.

### Daily Responsibilities
* Monitor and investigate security alerts.
* Participate in SOC discussions and knowledge sharing.
* Work with other teams to improve security.
* Continuously learn about new cyber threats and defenses.

---

## 👥 SOC Team Structure

| Role | Responsibility |
| :--- | :--- |
| **Junior SOC Analyst** | Monitor alerts and perform initial analysis. |
| **Senior SOC Analyst** | Handle complex investigations and support junior analysts. |
| **SOC Engineer** | Maintain security tools and configure alert rules. |
| **SOC Manager** | Manage SOC operations and report to management. |
| **Incident Responder** | Respond to major security incidents when required. |
